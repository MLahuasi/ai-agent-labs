# Laboratorios

Este directorio contiene los laboratorios practicos del proyecto `ai-agent-labs`.

## Menu

| #   | Laboratorio                                         | Objetivo                                                                                                  |
| --- | --------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 01  | [Gemini API Config](./01-api-config/gemini/main.py) | Validar la configuracion inicial de Gemini API desde Python usando `google-genai` y variables de entorno. |
| 02  | [OpenIA API Config](./01-api-config/openia/main.py) | Validar la configuracion inicial de OpenAI API desde Python usando `openai` y variables de entorno.       |
| 03  | [Ollama API Config](./01-api-config/ollama/main.py) | Validar la configuracion inicial de Ollama API local usando `ollama` y modelos descargados.              |

## Ejecucion general

Desde el directorio del laboratorio:

```powershell
uv run python main.py
```
