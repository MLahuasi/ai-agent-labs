# 📚 Ingeniería de Agentes de IA

Repositorio de aprendizaje y experimentación práctica enfocado en fundamentos de IA generativa, integración de LLMs, RAG, herramientas, flujos agénticos y arquitecturas para agentes de IA.

El aprendizaje se complementa con prácticas de **AI-Assisted Software Engineering**, aplicando agentes de programación dentro de flujos de desarrollo estructurados, con planificación, especificaciones, validación humana, Git/GitHub y herramientas externas mediante MCP.

Guía para crear el entorno local, instalar dependencias y ejecutar el proyecto por primera vez.

## 🧠 [Fundamentos](./info/fundamentos/README.md)

Conceptos y laboratorios prácticos relacionados con:

- Integración con diferentes proveedores de LLM.
- System prompts.
- Conversaciones e historial.
- Streaming de respuestas.
- Tool calling.
- Flujos de ejecución agénticos.
- RAG.
- Embeddings y búsqueda vectorial.
- Guardrails.
- Selección, comparación y evaluación de modelos.
- Patrones y fundamentos de orquestación de LLMs.

## 🛠️ AI-Assisted Software Engineering

Como complemento al desarrollo de agentes de IA, también se explora el uso de agentes de programación dentro del ciclo de desarrollo de software.

Los temas incluyen:

- Planificación e implementación asistida por IA.
- Human-in-the-loop para revisión y validación.
- Spec Driven Development (SDD).
- Gestión del contexto de agentes de programación.
- Skills e instrucciones reutilizables.
- Subagentes especializados.
- Integración y uso de servidores MCP.
- Flujos de trabajo con Git y GitHub.
- Branches, Pull Requests y Git Worktrees.
- Validación de criterios de aceptación.
- Revisión, pruebas y verificación del código generado por IA.

Repositorio relacionado:

- [opencode-info](https://github.com/MLahuasi/opencode-info) — Notas, conceptos y laboratorios prácticos sobre OpenCode y desarrollo de software asistido por IA.
