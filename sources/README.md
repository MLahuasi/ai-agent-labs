# 🤖 IA GENERATIVA

Laboratorio práctico para aprender los conceptos fundamentales de IA Generativa mediante ejemplos, agentes, herramientas y RAG.

---

## 🧠 Fundamentos de IA Generativa

### 🤖 [System Prompt](./info/system-prompts.md)

Qué es un `System Prompt`, cómo influye en el comportamiento del modelo y cómo puede utilizarse para controlar el formato, el nivel de detalle y la calidad de las respuestas generadas.

### 📡 [Streaming de Respuestas](./info/streaming-response-flow.md)

Como los modelos de IA generan contenido de forma incremental, el streaming permite mostrar la respuesta en tiempo real mientras se produce. En esta sección se explica el flujo de eventos, la recepcion de chunks y la construccion de la respuesta completa dentro de la aplicacion.

### 🛠️ [Uso de Herramientas](./info/use-tools.md)

Cómo un agente puede utilizar herramientas externas para ampliar sus capacidades, consultar información o ejecutar acciones específicas.

### 🔎 [RAG ((Retrieval-Augmented Generation)](./info/rag.md)

Cómo un sistema `RAG` indexa documentación, realiza búsquedas semánticas y utiliza el contexto recuperado para mejorar las respuestas del modelo.
